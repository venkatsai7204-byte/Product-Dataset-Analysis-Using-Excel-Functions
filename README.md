# Product-Dataset-Analysis-Using-Excel-Functions
An Excel data analysis project demonstrating SUM, COUNT, AVERAGE, IF, SUMIF, COUNTIF, MIN, MAX, LEFT, RIGHT, and MID functions on a product dataset.
# Excel Data Analysis Project

## Description

This project is an Excel-based data analysis assignment using a product dataset.
The dataset contains information such as Product ID, Product Name, Brand Name,
Price, Quantity, Category, and other product-related details.

The project demonstrates the use of Excel formulas and functions to analyze,
categorize, and extract information from the dataset.

## Objectives

The main objectives of this project are to:

- Analyze product data using Excel formulas
- Calculate summary statistics
- Categorize products based on price
- Perform conditional calculations
- Extract specific information from Product IDs
- Practice commonly used Excel functions

## Excel Functions Used

### 1. SUM, COUNT & AVERAGE
- Calculate the total price of all products
- Count the total number of products
- Calculate the average product price

### 2. MIN & MAX
- Find the minimum product price
- Find the maximum product price

### 3. IF Function
Used to create a **Price Range** column:
- Price >= $500 → High Price
- Price < $500 → Standard Price

### 4. SUMIF & COUNTIF
- Calculate the total price of products in the Electronics category
- Count products with a price below $100

### 5. Text Functions
The project uses:
- LEFT() – Extract the first two characters from Product ID
- RIGHT() – Extract the last two characters from Product ID
- MID() – Extract the month information from Product ID
